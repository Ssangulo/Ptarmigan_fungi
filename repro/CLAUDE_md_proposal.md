```
# STABLE — reproducibility harness (repro/)

- `./repro/run_repro.sh cached|cold|checks <RUN_ID>` regenerates every appendix table/figure
  and checks it; logs in `repro/logs/<RUN_ID>/summary.md` (committed). Read `repro/README.md`.
  cached ≈ 1 h (46 min of it is script 6 Part B); cold ≈ 15-20 h (background only).
- Scripts write to `~/Ptarmigan/repro_sandbox/<RUN_ID>/` and stage into THIS checkout's
  `Supplementary/` (git diff = drift). Overrides used: S4_OUT_DIR, S5/S6/S7/S8/S9_OUT_ROOT +
  _SUPP_DIR, HMSC_OUT_ROOT/_SUPP_DIR, HMSC_NO_REUSE=1 (cold), S6_STOP_AFTER=H2|H2MECH|H3.
  Defaults unchanged, so plain runs still write canonical paths.
- Run it from a worktree or with Daniel's OK: it rewrites committed Supplementary files in
  the checkout it runs in, and refuses to start on a dirty Supplementary/Scripts.
- `repro/claims.csv` = registry of quoted numbers (expr on a table + verbatim snippet). When
  prose with a registered number is rewritten, update the snippet; a FAIL means either the
  data or the sentence moved.
- `repro/manifest.csv` = producer of every file under Supplementary/tables|figures. Pointer
  chunks (`<id>-source`) in the appendix are generated by `repro/make_stubs.py` from it —
  edit STUBS there, never the chunks; `repro/stub_visibility.py` must pass (no pointer inside
  a docs-only block).
- GOTCHA: CSVs that store ROUNDED values (top-5 shares at 2 dp, HMSC VP at 4 dp) can make a
  correctly-rounded prose number look wrong by one in the last digit — check against the
  unrounded source table, or accept the inclusive half-unit tie the checker allows.
```
